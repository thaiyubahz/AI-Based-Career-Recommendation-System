# 🎯 AI-Based Career Recommendation System – Skillithm

## 📌 Project Overview

**Skillithm** is an AI-powered career guidance platform designed to help college students and fresh graduates identify suitable IT career paths based on their skills, interests, learning preferences, and behavioral patterns.

The system uses Machine Learning techniques to analyze user responses, recommend suitable career paths, and provide structured learning roadmaps to help users achieve their career goals.

## ✨ Key Features

- **User Authentication:** Secure user registration and login.
- **Career Assessment:** Interactive questionnaire to evaluate interests, skills, and work preferences.
- **AI-Based Career Prediction:** Recommends suitable IT career paths using Machine Learning models.
- **Career Matching:** Displays recommended career options with matching percentages.
- **Personalized Learning Roadmaps:** Provides structured learning paths for selected careers.
- **Progress Tracking:** Helps users monitor their learning activities and goals.
- **Dashboard:** Displays career recommendations and learning progress.

## 🧠 Machine Learning Approach

The recommendation system uses a combination of machine learning techniques to analyze user profiles and predict suitable career paths.

### Model Architecture

- **K-Means Clustering:** Groups users based on their career profile characteristics.
- **XGBoost:** Performs career classification.
- **Support Vector Machine (SVM):** Supports classification based on user profile features.
- **Random Forest:** Provides an additional classification model.
- **Ensemble Learning:** Combines model predictions using a majority voting approach.

### Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## ⚙️ System Workflow

1. User registers and logs into the platform.
2. User completes a career assessment questionnaire.
3. The system processes the responses and creates a career profile.
4. Machine Learning models analyze the profile.
5. Suitable career paths are recommended.
6. Users explore personalized learning roadmaps.
7. Users track their learning progress through the dashboard.

## 🎯 Project Objective

The primary objective of Skillithm is to simplify career decision-making for students and fresh graduates by transforming their skills, interests, and preferences into personalized career recommendations and structured learning pathways.
